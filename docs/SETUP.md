# Настройка KEREGE

## Supabase
1. Создайте проект в Supabase Dashboard.
2. Откройте SQL Editor и выполните миграцию `supabase/migrations/202611160001_init.sql`.
3. В Authentication → Providers включите Email.
4. Для теста можно оставить подтверждение email включённым: после регистрации подтвердите письмо. URL возврата должен быть добавлен в Authentication → URL Configuration.
5. Скопируйте Project URL и publishable key из Project Settings → API Keys.

## Запуск сайта
Откройте `index.html` через HTTPS-хостинг (например GitHub Pages). При первом открытии введите Project URL и publishable key в экран подключения.

## Проверочный сценарий
1. Создайте аккаунт с ролью «Поставщик».
2. Войдите и опубликуйте тестовый товар.
3. Откройте сайт в другом браузере/инкогнито и создайте аккаунт «Покупатель».
4. Найдите товар и отправьте запрос.
5. Войдите обратно поставщиком и проверьте, что запрос отображается в кабинете.

## Ключи и безопасность
Publishable key можно использовать в клиенте только вместе с RLS. Secret/service_role key никогда не вставляйте в HTML/JS, Android-приложение или публичный репозиторий.
